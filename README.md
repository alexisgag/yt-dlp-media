# yt-dlp Media

Skill pour ChatGPT et Claude qui utilise [yt-dlp](https://github.com/yt-dlp/yt-dlp) pour récupérer des vidéos, de l’audio, des sous-titres ou des extraits.

- **Source du skill** · [SKILL.md](yt-dlp-media/SKILL.md)
- **Claude** · [Télécharger le ZIP](yt-dlp-media.zip?raw=true), puis l’importer dans **Customize → Skills**.

L’exécution nécessite un terminal, un accès réseau à la source et `yt-dlp`. Pour la fusion ou les conversions, installe aussi `ffmpeg`. Sur macOS avec Homebrew, utilise `brew install yt-dlp ffmpeg`.
